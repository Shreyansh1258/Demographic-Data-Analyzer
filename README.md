# 📊 Demographic Data Analyzer

## 📌 Overview

The **Demographic Data Analyzer** is a data analysis project that uses Python and Pandas to explore and analyze demographic data. It extracts insights related to age, education, work hours, salary, and more.

---

## 🚀 Features

* Analyze race distribution in the dataset
* Calculate average age of men
* Determine percentage of people with a Bachelor's degree
* Compare income levels based on education
* Analyze work hours and salary relationships
* Identify country-wise high earners
* Find the most common occupations among high-income individuals

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy (optional)

---

## 📂 Dataset

The dataset includes the following columns:

* age
* workclass
* fnlwgt
* education
* education-num
* marital-status
* occupation
* relationship
* race
* sex
* capital-gain
* capital-loss
* hours-per-week
* native-country
* salary

---

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/demographic-data-analyzer.git
   ```

2. Navigate to the project folder:

   ```bash
   cd demographic-data-analyzer
   ```

3. Install dependencies:

   ```bash
   pip install pandas
   ```

4. Run the script:

   ```bash
   python main.py
   ```
